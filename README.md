Kite é uma plataforma de inteligência artificial local que permite executar modelos de linguagem diretamente no navegador, utilizando WebLLM e WebGPU para aproveitar o hardware do próprio dispositivo.

O projeto foi desenvolvido com foco em privacidade, acessibilidade e flexibilidade, permitindo que o usuário carregue modelos de diferentes tamanhos conforme a capacidade do dispositivo. O sistema utiliza carregamento sob demanda e cache local para evitar downloads desnecessários, oferecendo um modelo inicial leve e opções mais avançadas para quem deseja maior capacidade de processamento.

Principais recursos
🤖 Execução local de modelos de linguagem
⚡ Inferência utilizando WebGPU
📦 Carregamento de modelos sob demanda
💾 Cache local para reutilização dos modelos
🧠 Suporte a diferentes níveis de modelos
🔒 Processamento local, reduzindo a necessidade de enviar conversas para servidores externos
🌐 Aplicação web hospedada na Vercel
🧩 Arquitetura modular preparada para memória, ferramentas e novos modelos

Kite — Local Intelligence, Everywhere.
